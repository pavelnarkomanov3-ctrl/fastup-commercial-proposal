# Конструктор коммерческих предложений FastUp

Статическая форма менеджера и клиентское КП в фирменном стиле fastup.by. Установка зависимостей и база данных не нужны.

## Запуск

```sh
npm start
```

Откройте http://127.0.0.1:8765/builder.html. Для уже работающего Live Server — http://127.0.0.1:5500/builder.html. Открытие через `file://` не подходит для загрузки JSON и JS-модулей.

## Рабочее пространство

На компьютере конструктор занимает высоту окна. Название компании, ссылка и кнопка копирования закреплены. В пункте 02 заголовок «Услуги для клиента» и пояснение закреплены; прокручивается только список услуг под ними. Предпросмотр имеет собственную прокрутку. Поля и кнопки в параметрах уменьшены для более плотного размещения.

На мобильных используется обычная прокрутка всей страницы без фиксированной высоты и без внутренних прокруток в параметрах. Высота предпросмотра подстраивается под его содержимое, включая раскрытие карточек. Отступ под сообщением о копировании уменьшен на компьютере и телефоне.

Введите компанию, выберите услуги и при необходимости форматы сайта. Проверьте КП и скопируйте ссылку.

## Параметры и цены

- Разработка: менеджер выбирает лендинг, корпоративный сайт и/или интернет-магазин. Клиент видит только выбранные форматы. Стартовые цены — от 1 100, 1 800 и 3 000 BYN соответственно, разовая стоимость проекта.
- Контекст: дополнительных переключателей нет. От 700 BYN за запуск одного сервиса на выбор — Google Ads или Яндекс.Директ. Дальнейшее ведение — от 700 BYN/мес. Если нужны обе площадки, стоимость выше и согласуется отдельно. Рекламный бюджет отдельно.
- Таргет: переключателя количества площадок нет. Запуск от 700 BYN, дальнейшее ведение от 700 BYN/мес. Дополнительные площадки и расширение объёма оплачиваются дополнительно по согласованию. Рекламный бюджет отдельно.
- SEO: первый месяц от 1 000 BYN, далее от 800 BYN/мес.
- GEO: аудит бесплатно, разовый проект от 1 200 BYN, ведение GEO и SEO от 800 BYN/мес. При совместном выборе SEO и GEO одинаковые работы не начисляются дважды.

На клиентской странице услуги представлены раскрывающимися плашками. Внутри — состав, условия, этапы и кнопка «Узнать больше», открывающая страницу услуги на fastup.by в новой вкладке. Для таргета используется главная fastup.by, поскольку отдельная профильная страница не была найдена. FAQ отсутствуют.

## Ссылки

```text
https://fastup.by/kp/?client=Город+и+Ромашки&services=web,ppc,target&web=corporate
```

`client` — название компании, `services` — коды услуг в порядке показа, `web` — выбранные форматы (`landing`, `corporate`, `ecommerce` через запятую). Форма использует URLSearchParams, название выводится обычным текстом.

Старые ссылки открываются с актуальным справочником. Если параметр `web` отсутствует, показываются все три формата сайта. Ранее использовавшиеся параметры `ppc` и `target` больше не формируются формой и не влияют на текущую базовую цену: в предложении показан один сервис на выбор и примечание о дополнительных работах.

## Файлы и публикация

Основные файлы: `index.html`, `builder.html`, `app.js`, `builder.js`, `styles.css`, `catalog.json`; фирменные ресурсы `fastup-logo.svg`, `Inter-Variable.woff2` и `GolosText-Variable.woff2` находятся рядом с ними в корне проекта. Для размещения скопируйте их вместе в `/kp/` или корень GitHub Pages. Относительные пути поддерживают подпапки. Форма строит ссылки на текущий адрес размещения; localhost предназначен для локальной проверки. Публикация в этой доработке не выполнялась.

Тексты и цены редактируются в `catalog.json`; автоматической синхронизации с fastup.by нет. Существующие ссылки получают изменения при следующем открытии. Цены форматов сайтов находятся в `packages`, базовые цены и условия остальных услуг — в `prices` и `terms`.

## Проверки

```sh
npm test
```

13 проверок покрывают ссылки, кириллицу и спецсимволы, фильтрацию форматов, базовые цены без выбора площадок, оговорку о доплате, отсутствие FAQ, раскрывающиеся плашки, кнопки перехода на сайт и ошибки справочника.

Визуальная проверка независимой прокрутки и узкого экрана не завершена: инструмент Chrome не предоставляет содержимое страницы. Эта проверка остаётся ограничением; логика и структура интерфейса проверены автоматически.


## Страница недоступного предложения

Некорректная ссылка и ошибка загрузки справочника показывают открытый экран без карточки-рамки: крупный адаптивный заголовок, пояснение, Telegram, два номера телефона и переход на сайт. Для ошибки загрузки предусмотрена повторная попытка. Контакты для аварийного случая доступны в `RECOVERY_CONTACTS` в `app.js`, даже если JSON не загрузился; при изменении телефонов обновляйте их вместе со справочником. Анимация появления и эффекты наведения учитывают настройку уменьшения движения. Основная логика некорректной ссылки сохранена.
